
# Таблица классификации данных

| Данные                                                                        | В чём необходимость защиты                                                          | Инструменты защиты                                                                                                       |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Медицинские заключения, результаты анализов, диагнозы                         | Высокий риск утечки медтайны → нарушение законодательства, потеря доверия пациентов | Шифрование на уровне полей/таблиц и файлов, диск/объектное шифрование, доступ по ролям, аудит доступа |
| Личные данные пациентов (ФИО, дата рождения, адрес, контакты, паспорт, СНИЛС) | Нарушение ПДн (152-ФЗ), идентификация при утечке                                    | Шифрование колонок, токенизация, маскировка в логах, удаление по требованию, хранение в пределах РФ                      |
| Договоры, реквизиты оплаты, банковские данные                                 | Утечка финансовых сведений, мошенничество                                           | TLS при передаче, шифрование BLOB / файла, доступ только для кассиров/бухгалтеров, аудит                                 |
| Журналы приложений и доступов                                                 | Часто содержат PII/идентификаторы, может использоваться для анализа действий        | Маскировка чувствительных полей, шифрование логов, ротация журналов, централизованное хранение лога с контролем доступа  |
| Метаданные / связи (ID пациента, идентификаторы записей)                      | При комбинировании с другими данными могут восстановить личность                    | Шифрование идентификаторов, псевдонимизация, токенизация                                                                 |
| Файлы вложений (сканы, изображения, PDF)                                      | Файлы могут содержать PII/мединформацию                                             | Шифрование файлов / объекта хранения, контроль доступа, проверка целостности                                             |
| Сырые данные в озере данных / архивах                                         | При доступе без защиты — источник утечки                                            | Шифрование всего хранилища, шифрование сегментов, контроль доступа, деперсонализация / маскирование перед аналитикой     |
