## Список данных для защиты и методы

| Класс              | Примеры                             | Методы защиты                                                                                      |
|--------------------|-------------------------------------|----------------------------------------------------------------------------------------------------|
| Медтайна           | диагнозы, результаты, назначения    | Шифрование БД/файлов, строгий RBAC/ABAC, логи доступа                                              |
| ПДн                | ФИО, паспорт/СНИЛС, адрес, контакты | Локализация в РФ, минимизация, шифрование колонок/полей, маскирование в логах, удаление по запросу |
| Финансы            | чеки, договоры                      | TLS, ограничение видимости                                                                         |
| Журналы/метаданные | техлоги                             | Маскировка, доступ только служебным ролям                                                          |
